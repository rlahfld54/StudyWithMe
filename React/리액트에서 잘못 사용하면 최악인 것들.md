1. 무분별한 useEffect 사용한 코드
   App.jsx에 useEffect가 7개나 있네요? 저번에 분명히 줄였는데 또 생겼습니다.
   저는 화면단 코드를 작성할때 제일 먼저 라이프사이클을 확인하는데요.
   마운트시 1번만 작동되어야하는 기능(마운트 전/후), 업데이트로 변경되어 재랜더링될 경우, 마지막 단계인 소멸단계에서 해야할 기능을 분리합니다.

   마운트시 1번만 실행되어야 할 기능에는 변수 초기화,데이터 요청 정도가 생각납니다.
   리액트에서는 props나 state로 데이터 상태변화를 감시하는데 이렇게 값이 변동될때 한곳에 모아서 useEfeect를 사용할 것 같습니다.
   하지만 전 이렇게 지저분한건 안좋아합니다.
   그냥 냅다 상태관리 라이브러리를 도입해서 몰아 넣고 싶은데요. 이것도 정말 한곳에 몰아버리면 지저분해집니다.
   여러 컴포넌트,페이지에서 자주 사용하는 데이터만 상태관리 라이브러리에 사용하고, 나머지는 컴포넌트마다 객체에 담아서 useEffect를 사용할 것 같습니다.

   일단 필요없는 코드를 지워도 오류없이 잘 돌아갑니다. 저 지금 정말 무섭습니다..ㅋㅋㅋ ㅠ
