## PostgreSQL를 선택한 이유

실무에서 PostgreSQL을 써본 적은 없지만, 메일딸깍 프로젝트를 만들면서 선택하게 되었습니다.
저는 새로운 툴을 고를 때 확장성과 직관적인 사용법을 가장 중요하게 생각합니다. 개발을 하다 보니 사용하기 편하고 확장성이 좋아야 결국 일할 때 차질이 안 생기더라고요. 자연스럽게 생긴 저만의 기준입니다.
요즘은 워낙 좋은 툴이 많이 나와서, 프로젝트 성능에 치명적인 문제가 있는 게 아니라면 뭘 써도 괜찮다고 생각합니다. 그런 면에서 PostgreSQL은 사용법이 직관적이고 확장성도 좋아서 제 기준에 딱 맞았습니다.

## 내가 만든 프로젝트의 코드로 공부하는 이유

일반적인 토이 프로젝트는 단순 기능 구현에 그쳐 실제 업무 수준과 괴리가 큽니다. 하지만 제가 만든 프로젝트는 실제 현업에서 겪은 불편함과 제약 조건을 해결하기 위해 기획되었습니다.
그렇기 때문에 공부자료에 좋다고 생각했습니다.
